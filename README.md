# Anti-Sleeping Glasses — Arduino

Glasses that wake the wearer up: an IR sensor on the frame watches the eye, and if it stays closed for more than 3 seconds the Arduino switches a relay that triggers an alert. 2022.

![Anti-sleeping glasses](https://user-images.githubusercontent.com/105288469/176274230-1af81d65-bfe5-476a-bca1-d90a95a6e462.gif)

[Watch the video](https://youtu.be/fWEhpXcb63Q)

**Hardware:** Arduino · IR eye-blink sensor (D4) · relay (D5) — `Anti_sleep_glasses.ino`
